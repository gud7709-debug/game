# Hanwha Taepyeongro PIXEL HUNT 3D

## Files

- `index.html`: WebGL game client
- `server.mjs`: Node.js WebSocket room server (up to 6 players)
- `render.yaml`: Render free Web Service configuration

## Local server

```bash
npm install
npm start
```

Open `http://localhost:8080`.

## Render deployment

Create a new **Web Service** from this GitHub repository and use the included `render.yaml`.
Choose the **Free** plan. Render provides the public server URL after deployment.
